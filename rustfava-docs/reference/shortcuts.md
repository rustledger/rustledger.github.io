# Keyboard Shortcuts

## General

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + O` | Open file |
| `Cmd/Ctrl + W` | Close current tab |
| `Cmd/Ctrl + Q` | Open query panel |
| `Cmd/Ctrl + ,` | Open settings |
| `Cmd/Ctrl + ?` | Show keyboard shortcuts |
| `F11` | Toggle fullscreen |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + 1-9` | Switch to tab 1-9 |
| `Cmd/Ctrl + Tab` | Next tab |
| `Cmd/Ctrl + Shift + Tab` | Previous tab |
| `Cmd/Ctrl + [` | Go back |
| `Cmd/Ctrl + ]` | Go forward |

## Editor

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + F` | Find in file |
| `Cmd/Ctrl + G` | Go to line |
| `Cmd/Ctrl + S` | Save file |
| `Cmd/Ctrl + Z` | Undo |
| `Cmd/Ctrl + Shift + Z` | Redo |

## Query

| Shortcut | Action |
|----------|--------|
| `Enter` | Run query |
| `Cmd/Ctrl + Enter` | Run query (from editor) |
| `Escape` | Close query panel |
| `Up/Down` | Navigate query history |

## Views

| Shortcut | Action |
|----------|--------|
| `G then A` | Go to Accounts |
| `G then I` | Go to Income Statement |
| `G then B` | Go to Balance Sheet |
| `G then J` | Go to Journal |
| `G then Q` | Go to Query |
