# Getting Started

Welcome to rustfava! This guide will help you get up and running in minutes.

## What is rustfava?

rustfava is a desktop application for viewing and managing Beancount/rustledger files. It wraps the Fava web interface in a native desktop application powered by Tauri and rustledger.

## Quick Links

- [Installation](/getting-started/installation) - Download and install rustfava
- [Quick Start](/getting-started/quick-start) - Open your first ledger file

## Requirements

- **Operating System**: Linux, macOS, or Windows
- **Ledger Files**: Beancount-format `.beancount` files

No other dependencies required - rustfava is a self-contained application.
