# Features

## Core Features

### Multi-file Management

Open and manage multiple ledger files with a tabbed interface. Quickly switch between different projects or accounts.

### Real-time Validation

See errors and warnings as you work. rustfava validates your ledger files instantly using rustledger's fast parser.

### Account Explorer

Browse your chart of accounts with an interactive tree view. Click to filter transactions by account.

### Query Interface

Run BQL queries directly in the app. View balances, income statements, and custom reports.

### Charts & Visualizations

Built-in charts for:
- Net worth over time
- Income vs expenses
- Account balances
- Cash flow analysis
